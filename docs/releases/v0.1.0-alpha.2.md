# OmniCodex v0.1.0-alpha.2

**Experimental public preview — not a stable or production-qualified release.**

## What is new

- **One preview-first setup path.** `python scripts/setup.py --apply` installs
  the profiles, agents, routing skill, Gemini Direct runtime, persistent defaults,
  and the same-session UserPromptSubmit hook. The asset-only installer remains
  available for conservative updates.
- **Persistent defaults.** New Codex sessions can start with OmniCodex Auto or a
  saved Economy/Balanced/Quality/Max policy without requiring a skill mention.
- **Same-session controls.** Ordinary messages such as `omni status`,
  `omni quality`, `omni reset`, and `omni save quality` control OmniCodex
  policy at prompt boundaries. Parent-model changes remain on Codex's native
  `/model` control.
- **Gemini Direct context offload.** Large, explicitly approved read-only context
  can be captured deterministically, sent directly to Gemini, and returned as a
  compact source-linked EvidencePack. Gemini receives no filesystem, shell, MCP,
  app, or subagent access.
- **No infrastructure detour.** Normal use does not require WSL, Ubuntu, Docker,
  FreeLLMAPI Desktop, or a second Codex installation. A missing
  `GEMINI_API_KEY` leaves native OmniCodex ready.
- **Fail-closed privacy.** Sensitive or unapproved private context is not
  externalized. External context offload is never an OpenAI quota fallback.

## Validation

GitHub Actions runs the complete Python unit suite, compiles the scripts, and
checks whitespace without making Gemini calls.

Maintainer Windows acceptance used Codex CLI 0.160.0. A live Gemini Direct
validation using `gemini-3.5-flash-lite` passed the small EvidencePack probe and
the synthetic 180 KB case while preserving workspace hashes. The synthetic case
reported roughly 45,000 estimated raw-context tokens compressed to about 195
estimated handoff tokens (about 99.6% estimated reduction).

Those figures describe the local handoff estimator. They do **not** prove API
billing, free-tier eligibility, subscription allowance savings, or equivalent
quality on every repository. Gemini model availability and pricing are controlled
by Google and the user's account.

## Install from Codex

Give Codex this repository URL and ask it to install OmniCodex. The intended
commands are:

```sh
python3 scripts/setup.py
python3 scripts/setup.py --apply
```

The preview writes nothing. Review any conflicts before using
`--replace-existing`. Codex may ask once to trust the installed local hook.
Restart cached Desktop/IDE sessions after setup.

To configure optional Gemini Direct offload, expose `GEMINI_API_KEY` to the
Codex process and restart the app if it was already running. Never commit the key.
`OMNICODEX_GEMINI_MODEL` is optional and defaults to
`gemini-3.5-flash-lite`.

Inside a configured conversation:

```text
omni status
omni balanced
omni quality
omni reset
omni save quality
```

Use `/model` when you want to change the running parent model.

## Remaining alpha boundaries

- Codex UI surfaces may differ in hook/config caching and must load the same
  `CODEX_HOME`.
- Gemini semantic claims remain untrusted until the premium parent verifies exact
  cited source ranges.
- Billing/free-tier status is not verified by OmniCodex.
- Jev/OmniClaude, Laya, automatic MCP installation, RTK rewriting, and persistent
  project memory remain separate or deferred.

No raw session IDs, local home paths, customer files, credentials, or private
logs are included in this release.
