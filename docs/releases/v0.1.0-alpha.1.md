# OmniCodex v0.1.0-alpha.1

**Experimental public preview — not a stable or production-qualified release.**

## Included

This update integrates PR #2 (installer and local profile fixes) and PR #3
(context/token-efficiency policies and offline diagnostics).

- Four namespaced profiles: Economy, Balanced, Quality, Max.
- Seven explicit model/reasoning worker roles. Balanced targets Sol/medium;
  Max targets Astra/high. Auto selects workers without changing a running parent.
- An installer with conflict checks, backups, hashes, and a rollback-oriented
  manifest that preserves the base Codex configuration.
- The complete routing skill, including `references/efficiency.md`. This release
  fixes the integration gap where the older installer copied only `SKILL.md`.
- Optional Context Mode/codebase-memory-mcp workflows, native fallback, focused
  evidence retrieval, and compact handoffs. Providers are not bundled or installed.
- Offline doctor/planner tooling, asset/installer/policy regression tests, and
  a benchmark protocol. No paid model calls are made by CI or release automation.

## Validation provenance

The maintainer reported 26 efficiency tests passing on macOS arm64 with Python
3.12.14 and Codex CLI 0.153.4. A subsequent persisted, sequential Balanced test
recorded Sol/medium in three parent turns, Luna/low in a real child, and
Terra/medium in a real child, without Astra or additional agents.

These are reports of **local Codex execution records**, not independent
provider-side telemetry. The raw Mac records are not shipped in this release.
An earlier test recorded in PR #2 covers other profiles and roles, including Max,
and discloses a planner sentinel output mismatch. That broader report is not a
new runtime test of this combined release.

The combined Python suite and installer-reference regressions must pass in GitHub
Actions before automatic publication. Source tests do not replace runtime tests.

## Install/update

Use Python 3.11+ and a compatible Codex CLI. Smoke-test reports used Codex 0.153.4;
other builds and account entitlements must be checked independently.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/install.py
codex --strict-config -p omnicodex-balanced
```

For an existing installation, review the changes before explicitly using
`python3 scripts/install.py --replace-existing`. The backup location is printed.
No optional MCP server is installed by these commands. Profiles apply to new CLI
sessions, not existing Desktop/IDE tasks. Check your working directory's overrides.

Rollback instructions and earlier runtime observations are in
`docs/local-validation.md`. Remove/restore only the assets identified by the
manifest and preserve later user edits. Do not blindly restore or delete global configuration.

No raw session IDs, local home paths, customer files, credentials, or logs are
included in these release notes.
